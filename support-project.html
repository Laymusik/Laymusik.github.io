Как получен отчёт

SELECT status, COUNT(*) AS ticket_count
FROM tickets
GROUP BY status
ORDER BY status;

Запрос группирует заявки по статусу и считает записи в каждой группе.

Пример поиска срочных заявок

SELECT id, title, status, priority
FROM tickets
WHERE status = 'new' AND priority = 1;
