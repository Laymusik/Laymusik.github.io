Учебный проект · PostgreSQL

База заявок технической поддержки

Развернул PostgreSQL в Docker и создал базу для учёта заявок: тема обращения, статус, приоритет и время решения. Отработал путь заявки от регистрации до закрытия.

PostgreSQL Docker SQL Учёт заявок
  • Настроил хранение данных в отдельном Docker-томе.
  • Создал таблицу с первичным ключом, обязательными полями и ограничениями допустимых статусов и приоритетов.
  • Добавил учебные заявки и выполнил выборки с фильтрацией и сортировкой.
  • Обновил статус заявки и зафиксировал время решения.
  • Составил отчёт по количеству заявок в каждом статусе с помощью GROUP BY и COUNT.

Результат: работающая учебная база и SQL-запросы для обработки заявок и простой отчётности.

Учебный проект · Автоматизация

Bash-скрипт проверки доступности сервисов

Создал скрипт для проверки главной страницы и бэкенда через Nginx reverse proxy. Скрипт запускается внутри Linux-контейнера и выводит результат в терминал.

Bash curl Docker HTTP
  • Проверяет HTTP-код каждого адреса с таймаутом 5 секунд.
  • Выводит OK или FAIL и возвращает код завершения 0 или 1.
  • Обнаружил недоступность бэкенда при учебной остановке.
  • Подтвердил восстановление после запуска бэкенда.

Результат: повторяемая проверка сервисов одной командой. Сохранение журнала не реализовано.
