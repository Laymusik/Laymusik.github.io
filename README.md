# Портфолио Алексея Жарикова

Статический сайт-портфолио с описанием учебных проектов
по сопровождению ИТ-систем и автоматизации.

🌐 Сайт: https://laymusik.github.io/

## Проекты

- **Веб-инфраструктура:** Docker Compose, Nginx reverse proxy,
  диагностика по логам, учебные сбои и восстановление,
  мониторинг через Blackbox Exporter, VictoriaMetrics и Grafana.
- **База заявок поддержки:** PostgreSQL, создание таблицы
  и ограничений, фильтрация, изменение статусов и отчётность.
- **Автоматизация:** Bash-скрипт проверки HTTP-доступности
  главной страницы и бэкенда с помощью curl.

## Что находится в репозитории

- `index.html` — главная страница портфолио.
- `backend/index.html` — описание проекта веб-инфраструктуры.
- `support-project.html` — снимок учебных данных PostgreSQL
  и примеры SQL-запросов.
- `404.html` — страница ошибки.
- `downloads/support-project.sql` — выгрузка учебной базы.
- `downloads/check-services.sh` — скрипт проверки сервисов.

Это публичная статическая версия портфолио.
Полная конфигурация локального Docker-стенда в этот
репозиторий не включена.

GitHub Pages публикует страницы, но не запускает PostgreSQL,
Nginx, Grafana или Bash-скрипты. Раздел `/backend/`
здесь является статической страницей, а не reverse proxy.

## Как изменить сайт под себя

1. Скачайте файлы через Code → Download ZIP.
2. Замените имя, описание опыта и тексты проектов в HTML-файлах.
3. Замените учебные материалы в `downloads` своими файлами.
4. Проверьте все ссылки и названия скачиваемых файлов.
5. Опубликуйте изменённую версию на выбранном статическом хостинге.

Стили находятся внутри HTML-файлов в блоках `<style>`.
Отдельная сборка сайта не требуется.

Ссылки начинаются с `/` и рассчитаны на размещение сайта
в корне домена. При публикации в подпапке их нужно адаптировать.

Перед публикацией проверьте, что в файлах и SQL-выгрузках
нет паролей, токенов, персональных или рабочих данных.

## Как использовать Bash-скрипт

Скрипту нужны Bash, curl и доступ к проверяемым сервисам.
Он рассчитан на запуск внутри frontend-контейнера
исходного учебного стенда.

При запуске в другой среде замените адреса в скрипте:
`localhost` обозначает среду, в которой выполняется скрипт.

Коды завершения:
- `0` — обе проверки успешны;
- `1` — хотя бы одна проверка завершилась неудачей.

Скрипт выводит результат в терминал; журнал не сохраняется.

## Данные и ограничения

SQL-выгрузка содержит учебную таблицу и тестовые заявки.
Восстанавливать её следует в отдельную учебную базу.

Страница с заявками — сохранённый снимок, а не живое
подключение к PostgreSQL. После изменения данных её нужно
сформировать повторно.

Проекты описывают учебную практику, а не готовую
промышленную систему. Настройка оповещений Grafana
на момент публикации не завершена.

репозитория. Если файл LICENSE отсутствует, явное разрешение
